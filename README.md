SK Loyalo School CMS Website

A dynamic school content management system (CMS) website developed for SK Loyalo School.
The platform allows administrators to manage and update website resources dynamically without modifying the source code manually.

Features
Dynamic content management
Admin dashboard for resource updates
Responsive modern UI
Event and announcement management
Gallery and media updates
Dynamic section editing
Contact and enquiry handling
Scalable frontend and backend architecture
Tech Stack
Frontend
React.js
HTML5
CSS3
JavaScript
Backend
Node.js
Express.js
